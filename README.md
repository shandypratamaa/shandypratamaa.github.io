# Shandy Putra — Personal Portfolio

I made this website to introduce myself and share the things I’ve worked on and enjoy learning about. It brings together my background, achievements, projects, research, and interests in one place, with photo galleries and interactive details throughout.

## Built with

- React and TypeScript
- Vite for development and production builds
- React Router for the site’s pages
- CSS for the responsive layouts, styling, and animations
- GitHub Pages and GitHub Actions for deployment

## Run locally

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal. To create a production build, run:

```sh
npm run build
```

The site is published at [shandypratamaa.github.io](https://shandypratamaa.github.io). Updates pushed to the `main` branch are built and deployed with GitHub Actions.
